SlicerROS2
==========

SlicerROS2 connects 3D Slicer with ROS 2 for robot visualization,
ROS topic/service/parameter integration, and image-guided robotics workflows.

Start with the overview and build instructions if you are new to the project.
Use the tutorials for complete workflows, and the reference pages when you need
details about MRML ROS nodes or testing.
